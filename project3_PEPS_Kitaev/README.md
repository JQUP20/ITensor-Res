# 项目3: PEPS模拟二维Kitaev模型

## 目标

用投影纠缠对态(PEPS)重现**非阿贝尔任意子液体**。

## 研究系统

**Kitaev蜂窝模型**

```
H = -Jₓ Σ_{x-links} σᵢˣσⱼˣ - Jᵧ Σ_{y-links} σᵢʸσⱼʸ - Jz Σ_{z-links} σᵢᶻσⱼᶻ
```

## 物理背景

- **拓扑序**: Z₂ 自旋液体
- **任意子**: e, m, ψ (费米子)
- **量子维数**: 𝒟 = 2
- **拓扑纠缠熵**: S_topo = ln(𝒟) = ln(2) ≈ 0.693
