# MERA与共形场论理论

## MERA简介

### 多尺度纠缠重整化拟设 (Multi-scale Entanglement Renormalization Ansatz)

MERA是一种分层次的张量网络，专门设计用于描述临界系统。

### 为什么需要MERA？

**MPS的局限**:
- 对临界系统效率低
- 纠缠熵对数增长 S ~ log L
- 需要指数大的键维度 χ ~ L^α

**PEPS的局限**:
- 收缩困难（指数复杂度）
- 对临界系统不够高效

**MERA的优势**:
- 多尺度结构自然匹配RG
- 对临界系统高效: χ ~ poly(log L)
- 显式实现实空间重整化群

## MERA结构

### 基本构件

#### 1. 等距张量 (Isometry)
```
    |
   / \
  u   u'
```

形状: $(χ, χ, χ)$

性质: $u^\dagger u = I$ (等距性)

**作用**: 粗粒化，减少自由度

#### 2. 解纠缠器 (Disentangler)
```
  |    |
   \  /
    w
   /  \
  |    |
```

形状: $(χ, χ, χ, χ)$

性质: $w^\dagger w = I$ (酉性)

**作用**: 去除短程纠缠

### MERA层次结构

```
     ●              ← 第3层 (粗粒)
    / \
   w   w            ← 解纠缠器
  / \ / \
 u   ●   u          ← 第2层
/ \ / \ / \
w   w   w          ← 解纠缠器
|   |   |   |
u   u   u   u      ← 第1层
|   |   |   |
●   ●   ●   ●      ← 第0层 (原始)
```

### 分支数 (Branching)

最常用: **二进制MERA** (branching = 2)
- 每个等距张量连接2个下层格点
- 系统尺寸按 L → L/2 缩小

## 实空间重整化群

### RG变换

MERA实现了**实空间RG**:

$$
|ψ_{n+1}⟩ = \prod_i u_i^\dagger \prod_j w_j^\dagger |ψ_n⟩
$$

其中:
- $|ψ_n⟩$: 第n层态
- $w_j$: 解纠缠器
- $u_i$: 等距张量

### 能量尺度

不同层对应不同能量尺度:

| 层 | 能量尺度 | 长度尺度 |
|----|---------|----------|
| 0  | UV      | a        |
| 1  | E₁      | 2a       |
| 2  | E₂      | 4a       |
| n  | Eₙ      | 2ⁿa      |

### 不动点

临界点 → **RG不动点**

MERA在每层应有相同结构（标度不变性）！

## 共形场论 (CFT)

### 为什么CFT？

**1D量子临界点 ↔ 2D CFT**（虚时间方向）

### 基本概念

#### 中心荷 (Central Charge)

描述系统"自由度数量"：

$$
c = \frac{3L}{2π^2} S(L)
$$

其中 S(L) 是纠缠熵。

常见值:
- **自由费米子**: c = 1/2
- **Ising**: c = 1/2
- **自由玻色子**: c = 1
- **Heisenberg自旋链**: c = 1

#### 标度维数 (Scaling Dimension)

算符的标度行为：

$$
⟨O(x)⟩ \sim x^{-Δ}
$$

Δ: 标度维数

**初级场 (Primary Fields)**:
- 满足特定变换性质
- 完全由Δ刻画

### CFT数据

一个CFT由以下确定:
1. **中心荷** c
2. **初级场标度维数** {Δᵢ}
3. **算符乘积展开系数** (OPE coefficients)

## MERA与CFT的联系

### 标度维数提取

从MERA的**标度算符** (Scaling Operators) 提取Δ:

$$
u^\dagger O u = λ O'
$$

标度维数:
$$
Δ = -\frac{\log λ}{\log 2}
$$

### 中心荷提取

从**纠缠熵**提取:

$$
S(L) = \frac{c}{3} \log L + s_0
$$

其中:
- c: 中心荷
- s₀: 非普适常数

### 关联函数

**CFT预言**:
$$
⟨O(x) O(0)⟩ \sim x^{-2Δ}
$$

**MERA计算**:
使用层次结构高效计算远距离关联

## 变分优化

### 目标

最小化能量:
$$
E = \frac{⟨ψ|H|ψ⟩}{⟨ψ|ψ⟩}
$$

其中 $|ψ⟩$ 是MERA态。

### 优化策略

#### 1. 逐层优化

从下往上：
1. 固定其他层
2. 优化当前层的 w 和 u
3. 迭代直到收敛

#### 2. 能量最小化

对每个张量：
```
min E[u, w]
```

使用:
- 梯度下降
- 共轭梯度
- 二阶方法

#### 3. 等距性约束

必须保持:
$$
u^\dagger u = I
$$

使用:
- QR分解
- SVD投影
- 流形优化

### 收敛判据

1. **能量收敛**: $|E_n - E_{n-1}| < ε$
2. **梯度范数**: $||∇E|| < δ$
3. **等距性误差**: $||u^\dagger u - I|| < η$

## 临界Ising模型示例

### 哈密顿量

$$
H = -J \sum_i (σ_i^x σ_{i+1}^x + h σ_i^z)
$$

临界点: $h = 1$ (横场)

### CFT数据

- **中心荷**: c = 1/2
- **初级场**:
  - 单位算符: Δ = 0
  - 能量密度: Δ = 1/2
  - 自旋: Δ = 1/16
  - 无序参数: Δ = 1/16

### MERA表示

临界Ising态可以用**小键维度** MERA精确表示！

典型: χ = 6 已经非常准确

## 数值签名

### 如何识别临界点？

1. **纠缠熵**: S ~ c/3 log L
2. **关联长度**: ξ → ∞
3. **能隙**: Δ → 0
4. **标度不变性**: 每层相同

### MERA vs MPS

| 性质 | MPS | MERA |
|------|-----|------|
| 临界熵 | S ~ log L | S ~ log log L |
| 键维度 | χ ~ L^α | χ ~ const |
| 计算复杂度 | O(χ³) | O(L log L χ³) |
| RG结构 | 无 | 显式 |

## 高级主题

### 1. 张量网络重整化 (TNR)

MERA的推广:
- 更灵活的截断
- 更好的数值稳定性
- 但失去严格等距性

### 2. 修改MERA (Modified MERA)

改进:
- 不同层不同χ
- 自适应截断
- 优化的解纠缠器放置

### 3. 高维推广

**2D MERA**:
- 更复杂的层次结构
- 计算更昂贵
- 仍是活跃研究

### 4. 费米子MERA

特殊考虑:
- 费米子奇偶性
- 反对易关系
- 粒子数守恒

## 计算复杂度

### MERA操作

**收缩**:
- 单层: O(χ³)
- 全部L层: O(log L · χ³)

**优化**:
- 单张量: O(χ⁶)
- 一次扫描: O(log L · χ⁶)

### 内存

- 存储MERA: O(log L · χ³)
- 远小于MPS的 O(L χ²)
