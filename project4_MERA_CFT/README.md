# 项目4: MERA提取CFT中心电荷

## 目标

从多尺度纠缠重整化Ansatz (MERA)层级提取**共形场论数据**。

## 研究系统

**一维伊辛模型临界点** (h_c = J)

```
H = -J Σᵢ σᵢᶻσᵢ₊₁ᶻ - h_c Σᵢ σᵢˣ
```

## 理论框架

### MERA结构
```
      ●        (顶层)
     ╱╲
    ●  ●       (等距张量)
   ╱╲╱╲
  ● ●●●●       (酉+等距)
```

### CFT对应
- **标度维度**: Δ_σ = 1/8, Δ_ε = 1
- **中心电荷**: c = 1/2
- **全息对偶**: AdS₃/CFT₂

## 任务清单

- [ ] 构建二元MERA
- [ ] 优化酉/等距张量
- [ ] 每层计算标度维度
- [ ] 拟合关联函数
- [ ] 提取中心电荷
- [ ] 验证共形塔

## 关键公式

### 中心电荷提取
```
c = 6 lim_{l→∞} [S(l) - S(l-1)] / ln(3)
```

### 标度维度
```
⟨σ(0)σ(r)⟩ ~ r^(-2Δ_σ)
```
